Code Review for GLUE Logic (ATF1 & ATF2)

I found several issues, ranging from critical bugs to minor style points. Here's my analysis:
ATF1 Issues
🚨 BUG: DEVICE_AREA MR Encoding Wrong
cupl
 
  
 
 
/* Your comment says: */
DEVICE_AREA    MR = 4;    0100

/* But your code produces: */
MR1 = !BA & ( ... DEVICE_AREA ... );  /* sets bit 1 */
MR2 = !BA & ( ... DEVICE_AREA ... );  /* sets bit 2 */
/* Result: MR = 0110 = 6, NOT 4! */
 
 

Fix: Remove DEVICE_AREA from MR1:
cupl
 
  
 
 
MR1 = !BA & (
      EMS2_WINDOW
    # ROM_AREA
    # REG2
    # REG3
    # REG_MIRROR
    );
 
 
⚠️ QUESTIONABLE: RAM.OE and ROM.OE
cupl
 
  
 
 
RAM.OE  = !EMS_WINDOW & !BA; /* managed by ATF2 */
ROM.OE  = !EMS_WINDOW & !BA; /* managed by ATF2 */
 
 

These are chip selects (active-low), not data outputs. They should probably always be driven. Either remove the .OE definitions or set them to TRUE. If ATF2 needs to override them, the design should be clear about which PLD "wins" when both try to drive.
⚠️ MINOR: Redundant Expression
cupl
 
  
 
 
[D2] = REG7 & ROM_SIZE2
     # REG6 & !REG6;    /* This is always FALSE */
 
 

Just use:
cupl
 
  
 
 
[D2] = REG7 & ROM_SIZE2;
